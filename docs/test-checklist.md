## Нефункциональность

- [x] Карта загружается < 2 секунд (факт ~0.15 с)
- [x] Нет ошибок в консоли (0 ошибок, 0 предупреждений)
- [x] Интерфейс работает на экране 320 px
- [x] Объём статики ≤ 500 KB (факт ~52 KB)
- [x] Ответ сервера ≤ 2 секунд (факт ~0.02–0.05 с)

## Обработка ошибок

- [x] При занятом объекте — понятное сообщение с подсказкой
- [x] При некорректной дате — сообщение с указанием причины
- [x] При превышении вместимости — сообщение с указанием лимита
- [x] При часах вне диапазона 1–12 — сообщение с указанием границ
- [x] При недоступном сервере — подсказка «проверьте, запущен ли сервер»
- [x] При неизвестном маршруте — ответ 404
- [x] При некорректном JSON — ответ 400, сервер не падает
- [x] При попытке отменить завершённую бронь — ответ 409

## Распределение ролей

| Роль | Область | Что проверил |
|------|---------|--------------|
| Тестировщик 1 | Функциональность: бронирование, статусы, чек | TC-01…TC-13, TC-25…TC-35 |
| Тестировщик 2 | Нефункциональность: скорость, адаптивность, объём | TC-42…TC-44, замеры метрик |
| Тестировщик 3 | Обработка ошибок | TC-36…TC-41 |

Работа велась индивидуально, роли объединены: функциональность и обработка
ошибок проверялись в основном автоматическими тестами, нефункциональность —
вручную.
