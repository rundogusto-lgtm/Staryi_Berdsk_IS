## BR-01: Пустое тело запроса возвращает 404 вместо 400

- **Связанный тест-кейс:** TC-10
- **Приоритет:** средний
- **Статус:** исправлено
- **Компонент:** `src/services/bookingService.js`, функция `validateBookingInput`

**Предусловие:** сервер запущен, база заполнена сидом.

**Шаги воспроизведения:**
1. Выполнить `POST /api/bookings` с пустым телом `{}`.
2. Посмотреть код ответа и текст ошибки.

**Ожидаемый результат:** код 400, текст вида «Не указан objectId». Отсутствие
обязательного поля — это ошибка ввода, пользователь должен понять, что не так.

**Фактический результат:** код 404, текст «Объект не найден». Клиент и
пользователь получали сообщение о поиске объекта, хотя объект никто не искал.

**Причина:** `validateBookingInput` начиналась с `getObjectById(objectId)`.
При `objectId === undefined` выборка возвращала `null`, и функция возвращала
строку «Объект не найден», которую `assertBookingInput` превращала в
`NotFoundError` с кодом 404. Проверки наличия обязательных полей не было вовсе.

**Решение:**
1. Добавлена проверка обязательных полей до обращения к БД: отсутствующий или
   пустой `objectId` даёт «Не указан objectId», нечисловой — «objectId должен
   быть целым числом». Обе ситуации считаются ошибками ввода (400).
2. Дополнительно устранён связанный риск: `objectId`, пришедший из JSON строкой,
   теперь приводится к числу через `Number()`. Раньше значение `'2'` могло
   сохраниться в SQLite как текст, что ломало бы сравнение и сортировку.

**Проверка после исправления:**
- `POST /api/bookings` с `{}` → 400 «Не указ��н objectId»
- `POST /api/bookings` с `{"objectId": "abc"}` → 400 «objectId должен быть целым числом»
- `POST /api/bookings` с `{"objectId": "2", ...}` → 201, в базе `object_id` = 2 (число)
- `GET /api/objects/999` → по-прежнему 404 «Объект не найден» (404 сохранён
  для действительно несуществующего объекта)

**Коммит:** `f8baa69`

**Почему дефект не нашли раньше:** до этого дня маршруты проверяли результат
сервиса вручную и не имели автотестов, а модульных тестов на пустое тело не было.
