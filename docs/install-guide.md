# Руководство по установке
## «Старый Бердск» — веб-система управления арендой объектов парка отдыха

**Версия:** 1.0

---

## 1. Требования
- Браузер: Chrome / Firefox / Edge последних версий.
- Node.js: 22+ (разработка и запуск; проверено на Node 24).
- Git.
- Сборка C++ не требуется: `better-sqlite3@12` ставится готовым бинарником.

## 2. Установка

```bash
git clone https://github.com/rundogusto-lgtm/Staryi_Berdsk_IS.git
cd Staryi_Berdsk_IS
npm install
npm run seed
npm start
```

Сервер: `http://localhost:3000`. Порт меняется переменной `PORT`:

```bash
PORT=8080 npm start
```

## 3. Настройка

| Параметр | Где | Значение по умолчанию |
|----------|-----|----------------------|
| Порт | `process.env.PORT` | 3000 |
| База данных | `data/park.db` (SQLite) | создаётся при `migrate()` |
| Тестовая база | `process.env.TEST_DB` | `tests/test.db` при `npm test` |
| Справочник объектов | `data/objects.json` | 8 объектов, загружается `npm run seed` |
| Горизонт записи | `MAX_DAYS_AHEAD` в `bookingService.js` | 90 дней |
| Лимит часов | `MIN/MAX_BOOKING_HOURS` | 1–12 |

Константы фронтенда (`MIN/MAX_BOOKING_HOURS` в `src/public/api.js`)
синхронизированы с серверными — менять парой.

## 4. Развёртывание

Локальный сервер (`npm start`) отдаёт и API, и фронтенд — этого достаточно
для защиты практики. Отдельный хостинг не настроен; для GitHub Pages
потребовался бы внешний API-хост, т.к. Pages отдаёт только статику.

## 5. Проверка и тесты

```bash
npm test             # 40 unit-тестов (Vitest)
npm run test:coverage  # отчёт о покрытии (нужен @vitest/coverage-v8)
```

Ожидается: 40 passed, покрытие `src/services` ~93%.

## 6. Решение проблем

| Симптом | Причина и решение |
|---------|-------------------|
| `npm install` требует Visual Studio / node-gyp | Стоит старый `better-sqlite3@11`. Обновитесь до v12 (`npm install`), у него есть prebuilt под Node 24 |
| `npm test` меняет `data/park.db` | Тесты должны выставлять `TEST_DB` до импорта `db.js` — так уже сделано в `tests/booking.test.mjs`; не запускайте тесты из другой рабочей папки |
| «Нет связи с сервером» в браузере | Сервер не запущен — выполните `npm start` и обновите страницу |
| Порт 3000 занят | Запустите с другим портом: `PORT=8080 npm start` |
| Пустая карта (0 объектов) | Не выполнен сид — запустите `npm run seed` |
| Ошибка 409 «Слот уже занят» | Дата и объект уже забронированы — выберете другой слот |
