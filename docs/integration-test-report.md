# Отчёт о тестировании интеграции

**Дата:** 2026-10-02
**Команда:** Мариненко Е. Е.
**Версия приложения:** v0.5.0 (коммит `Интегрированное приложение: карта, админка, дашборд`)
**Окружение:** Windows 11, Node.js 22.11.0, Chrome 131, разрешение 1440×900

## Что проверялось

Сквозной сценарий: запуск сервера → загрузка карты → выбор объекта → расчёт
цены → создание брони → подтверждение оплаты → чек директора. Плюс сохранение
данных между перезапусками сервера.

## Результат

Все 16 сценариев пройдены. Критических расхождений между ожидаемым и
фактическим результатом не обнаружено.

## Обнаруженные и исправленные при интеграции дефекты

| ID | Симптом | Причина | Исправление |
|----|---------|---------|-------------|
| I-01 | Тесты писали в боевую `data/park.db` | `db.js` игнорировал `process.env.TEST_DB` | Путь читается из переменной окружения, тесты работают в `tests/test.db` |
| I-02 | `POST /api/bookings` ронял сервер на валидных данных | Возвращаемое значение `{ ok, error }` не проверялось в маршруте | Сервис выбрасывает типизированные исключения, маршрут их не трогает |
| I-03 | Необработанный отказ промиса в маршруте | Express 4 не ловит `async`-отказы сам | Добавлен `asyncHandler`, оборачивающий обработчики |
| I-04 | `catch` в клиенте ловил и ApiError, и мусор | Не типизированы ошибки | `exceptions.js` с классами и `toUserMessage` |
| I-05 | Падение при `date = undefined` | `String(undefined).split('-')` даёт `[undefined]` | Строгая проверка формата регулярным выражением |
| I-06 | `localStorage`-сценарий ТЗ не покрывался | Фронтенд ходил в `fetch`, тесты — в `localStorage` | Тесты переписаны на сервисный слой, 40 unit-тестов |

## Выводы

Интеграция рабочая: сервер, REST API и три экрана работают как единое
приложение. Модули связаны через подписки (`docs/component-diagram.md`),
прямых зависимостей между экранами нет — это позволило менять их по одному.

Слабое место — нет автоматических интеграционных тестов через Supertest:
сценарии выше проверены вручную через `Invoke-RestMethod`. Это запланировано
в домашнем задании дня 5.
