# Диаграммы проекта

**Дата:** 2026-10-09
**Проект:** «Старый Бердск»

Диаграммы восстановлены по фактическому коду и служат заменой диаграммам,
необходимым по заданиям дней 1–3.

## Состав

| Файл | Диаграмма | День | Назначение |
|------|-----------|------|-----------|
| `use-case.md` | Прецедентов (Use Case) | 1 | Границы системы и роли пользователей |
| `class-diagram.md` | Классов (Class) | 2 | Структура кода: сервер, модель данных, фронтенд |
| `erd.md` | Сущность-связь (ER) | 2 | Структура базы данных в 3НФ |
| `activity-diagram.md` | Деятельности (Activity) | 3 | Алгоритм бронирования, смены статуса, отмены |
| `state-diagram.md` | Состояний (State Machine) | 3 | Жизненный цикл брони |
| `sequence-diagram.md` | Последовательностей (Sequence) | 3 | Порядок взаимодействия модулей |

Компонентная диаграмма находится отдельно: `docs/component-diagram.md`.

## Как открыть

Диаграммы написаны на Mermaid. Отрисовываются в:

- GitHub — в блоках ```mermaid``` автоматически;
- VS Code — расширение «Markdown Preview Mermaid Support»;
- [mermaid.live](https://mermaid.live) — вставить содержимое блока;
- любой Markdown-редактор с поддержкой Mermaid.

## Как экспортировать в изображение или Visio

Для сдачи обычно требуют PDF или `.vsdx`. Два способа:

1. **PDF** — открыть `mermaid.live`, вставить код блока, нажать
   `Actions → PNG`, затем распечатать в PDF.
2. **Visio** — экспортировать PNG и вставить в Visio, при необходимости
   перерисовать фигуры в фирменных элементах.

## Соответствие коду

Каждая диаграмма описывает реально существующие модули. Таблица соответствия
приведена в файле `class-diagram.md` в разделе «Соответствие коду».

Правила предметной области, вынесенные в диаграммы:

| Правило | Где отражено |
|---------|--------------|
| Часы от 1 до 12 | Activity, UC-02 |
| Горизонт записи 90 дней | Activity, UC-02 |
| Сезонный коэффициент | UC-03, Activity |
| Один слот — одна бронь | Activity (проверка в транзакции), UC-02 |
| Завершённую бронь отменить нельзя | State, Activity |
| Чек только по оплаченной броне | UC-06 |
| Типы объектов: gazebo, tent, parking | ER (`CHECK`) |
