## Что дало наибольшую пользу

Интеграционные тесты через Supertest. До их появления REST API не был
проверен ни одним автотестом: 34 маршрута, каждый из которых мог вернуть
неверный код, а ошибка обнаружилась бы только вручную. Именно они нашли BR-01 —
баг, который существовал с дня 5 и не проявлялся при ручном прогоне типовых
сценариев.

## Вывод

Приложение готово к защите. Функциональность проверена полностью: 44 из 44
тест-кейсов пройдены. Единственный найденный дефект устранён и закрыт
автотестом, поэтому повториться он не может. Критических и высоких дефектов нет.

Оставшиеся ограничения указаны честно:

- **Фронтенд не покрыт автотестами** (0 % строк из ~1300). Отрисовка карты,
  работа форм и печать чека проверяются только вручную. Это осознанный выбор:
  для проверки DOM потребовался бы jsdom или Playwright. При выявлении нового
  дефекта в интерфейсе рекомендуется заводить ручной кейс в `docs/test-cases.md`.
- **Печать чека** проверялась в диалоге предпросмотра браузера, реальный
  принтер не использовался.
- **Поведение при недоступности сервере** проверялось вручную один раз; автотест
  для него не написан, так как требует остановки процесса сервера.
