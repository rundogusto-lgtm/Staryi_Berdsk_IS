# Changelog

## [1.1.0] — 2026-10-09

Тестирование, исправление дефекта ручного тестирования, восстановленные
диаграммы и полный комплект документации по практике.

### Добавлено
- **Интеграционные тесты REST API** на Supertest — 34 теста. Раньше ни один
  маршрут не был проверен автоматически.
- **Тесты нормализации ошибок** — 12 тестов на `toUserMessage` и `guard`.
- Непрерывный запуск тестов: `.github/workflows/test.yml` (push и pull request),
  отчёт о покрытии сохраняется как артефакт.
- Конфигурация тестов и покрытия: `vitest.config.js`.
- UML-диаграммы: прецедентов, классов, ER, деятельности, состояний, последовательностей
  — в `docs/diagrams/`.
- Тестовые сценарии (15) и тест-кейсы (44): `docs/test-scenarios.md`, `docs/test-cases.md`.
- Чек-лист, протоколы (44) и баг-репорт: `docs/test-checklist.md`,
  `docs/test-protocols.md`, `docs/bug-reports.md`, `docs/test-summary.md`.
- Отчёт о покрытии тестами: `docs/test-coverage.md`.
- Дневник учебной практики за дни 1–16: `docs/diary.md`.

### Исправлено
- **BR-01: пустое тело запроса возвращало 404 вместо 400.** Отсутствие
  обязательного поля маскировалось под «объект не найден». Добавлена проверка
  обязательных полей до обращения к базе.
- **`objectId` из JSON приводится к числу.** Строковое значение могло сохраниться
  в SQLite как текст и сломать сравнение и сортировку.
- **Заливка объектов карты** — объекты отображались чёрным вместо зелёного
  (свободно) и красного (занято): класс `map-object--free` не устанавливался.
- **Подписи на карте** вынесены из фигур: текст обрезался внутри треугольника
  палатки и узкого прямоугольника парковки.

### Изменено
- Приложение вынесено из `src/server.js` в `src/app.js`. Точка входа теперь
  только запускает сервер, а само приложение импортируется в тестах без
  открытия сетевого порта.
- Тесты разведены по двум файлам баз данных (`tests/test.db` и
  `tests/api.test.db`): Vitest запускает файлы параллельно, общая база
  приводила к гонке за данные.
- Тестовая база и её журналы добавлены в `.gitignore`.

### Метрики

| Тестов | 40 | **89** |
| Покрытие серверной части | 92,8 % (только сервисы) | **98,5 %** (весь сервер) |
| Покрытие маршрутов REST | 0 % | **100 %** |
| Тестовых файлов | 1 | 3 |

## [1.0.0] — 2026-10-08

MVP веб-системы управления арендой объектов парка отдыха «Старый Бердск».

### Добавлено
- Интерактивная SVG-карта парка с 3 типами объектов (беседки, палатки, парковки).
- Система бронирования с расчётом цены и сезонными коэффициентами.
- Панель администратора (подтверждение оплаты, смена статусов, отмена).
- Дашборд директора (выручка, статистика по статусам, последние операции).
- Печать чека в формате А4.
- Обработка исключительных ситуаций (15 сценариев, типизированные ошибки).
- Unit-тесты бизнес-логики (40 тестов, Vitest).
- Документация: стандарты кодирования, диаграмма компонентов, отчёты
  об отладке, интеграции, инспекции и метриках качества.

### Исправлено
- Проверка занятости объекта (транзакция против двойной брони).
- Приём несуществующих дат (30 февраля) и мусора в поле даты.
- Запись тестов в боевую базу (переменная `TEST_DB`).
- Необработанные отказы промисов в Express 4 (`asyncHandler`).
- 9 несоответствий по итогам инспекции кода (день 11): дублирование
  справочника объектов, магические числа и строки, длинные строки, JSDoc.

### Изменено
- Рефакторинг кода по итогам инспекции (день 11).
- `better-sqlite3` обновлён с v11 до v12 (prebuilt-бинарники под Node 24).
- Покрытие сервисного слоя — 92.8 %.

### Технологии
- Node.js + Express, SQLite (better-sqlite3).
- Фронтенд без сборки: ES-модули, SVG-карта.
- Тесты: Vitest (+ `@vitest/coverage-v8`).
